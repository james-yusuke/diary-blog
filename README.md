## 広告配置

本文の読みやすさを優先し、トップページはTopics下（PCのみ）と一覧末尾、記事ページは本文末尾と右側（幅1200px以上）に広告を配置しています。検索・タグ一覧・About・404には広告枠を設けていません。

提供された6種類のバナーを画面幅と掲載場所に応じて使い分け、1ページ最大2枠、スマホは1枠としています。横長バナーは728×90 / 468×60 / 320×50から収まるものを選び、収まらない幅では表示しません。広告は表示領域に近づいてから専用iframeに読み込みます。

配置・サイズを指定しない `pl31377515` / `pl31377516` のスクリプトは、読書体験を優先して導入していません。広告の実配信は配信元の設定・在庫・閲覧環境に依存します。
